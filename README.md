# 🚀 Todo App Pro

A modern and responsive Todo List application built with **React.js**. Organize your daily tasks, track your progress, and manage your productivity with a clean and intuitive interface.

## ✨ Features

- **Add Tasks:** Create tasks with a title and description.
- **Edit Tasks:** Update existing task information.
- **Delete Tasks:** Remove tasks you no longer need.
- **Complete Tasks:** Mark tasks as completed or pending.
- **Live Search:** Search tasks instantly by title.
- **Task Filtering:** Filter tasks by All, Completed, and Pending.
- **Task Statistics:** Track total, completed, and pending tasks.
- **Local Storage:** Automatically save tasks and restore them after refreshing the page.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useState`, `useEffect`)
- Browser Local Storage
- Vite



## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone git remote add origin https://github.com/elbrins8850/To-Do-List-React.git


```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
